# automation — the automation agents' package (pointer)

AU — automation agents: designed and planned in `collite-gh/project/kantheon/features/automation-agents/`
(`design/design.md`, `implementation/hartland/`). This folder holds the package of `12` §6 from P2 on: the
`automation` TTR-M package, the literate recipes (EN and their committed CZ twins), their derived `.ttrp`, and
the golden cases.

Until then the extension it runs on is in `../model/` — the documents (`model/er/orders.ttrm`,
`returns-flow.ttrm`, `proposals.ttrm`), their words (`model/lexicon/{en,cs}/automation.ttrm`) and the world the
recipes name (`model/worlds/demo.ttrm`); see the "Automation extension" paragraph of `../model/README.md`.
